# Leads Dashboard — Аналитика первичных лидов

## Описание таблиц

Все таблицы находятся в `src/queries/acquisition/` и материализуются в схему `dash`. Каждая таблица содержит данные по всем странам (мультистрановое темплейтирование).

---

### leads_regs

Все регистрации пользователей. Основная точка входа в воронку.

| Поле | Тип | Описание |
|------|-----|----------|
| country | text | Страна |
| user_id | int | ID пользователя |
| user_type | text | Тип пользователя (STANDARD_USER и др.) |
| reg_date | date | Дата регистрации |
| gender | text | Пол (male/female/unknown) |
| user_age | numeric | Возраст на момент регистрации |
| city | text | Город |
| device_type | text | Тип устройства (ios/android/unknown) |
| qual_lead | bool | Квалифицированный лид (заполнен пол, имя, активный город, STANDARD_USER, возраст >= 18/16) |
| reg_with_guest | bool | Активировал гостевой доступ в течение 13 дней после регистрации |
| reg_with_ref | bool | Активировал реферальный промокод в течение 13 дней после регистрации |
| guest_ref | text | Канал активации: `guest_act`, `ref_act`, `guest_ref_act`, `w/o ref/guest` |
| purchase_date | date | Дата первой покупки (окно 45 дней) |
| days_to_purchase | int | Дней от регистрации до покупки |
| purchase_price | numeric | Сумма покупки |

**Окно конверсии:** 45 дней от регистрации.

## Структура дэшборда

### Tab 1: Overview

Общая картина по всем типам лидов.

**KPI-карточки (Big Number):**
- Всего лидов за выбранный период
- Общая конверсия в покупку (%)
- Средний чек (purchase_price)
- Медианное время до покупки (days_to_purchase)

**Графики:**
1. **Тренд лидов по дням** — stacked area chart, разбивка по типу лида (regs / guests / referrals / comebacks). Динамика и доля каждого канала.
2. **Конверсия по типу лида** — bar chart. Какой канал конвертит лучше.
3. **Тренд конверсии по неделям** — line chart по типам лидов. Как конверсия меняется во времени.
4. **Распределение выручки по типу лида** — pie/donut chart по сумме purchase_price.

**Фильтры:** country, date range, lead type.

---

### Tab 2: Соцдем-сегментация

**Графики:**
1. **Конверсия по полу** — bar chart (male / female / unknown). Объём лидов + CR.
2. **Конверсия по возрастным когортам** — бакеты: 16-20, 21-25, 26-30, 31-35, 36-40, 41+. Bar chart с количеством лидов и CR.
3. **Конверсия по городам** — таблица, top-20. Колонки: город, кол-во лидов, CR, средний чек.
4. **Конверсия по устройству** — bar chart (ios / android / unknown).
5. **Heatmap: пол x возрастная группа** — конверсия на пересечении. Самые горячие и холодные сегменты.
6. **Heatmap: город x устройство** — для крупных городов, CR по устройствам.
7. **Средний чек по соцдем-сегментам** — те же разрезы (пол, возраст, город), метрика — avg(purchase_price).

---

### Tab 3: Воронка и скорость конверсии

1. **Распределение days_to_purchase** — histogram. На какой день чаще всего покупают.
2. **Распределение days_to_purchase по типу лида** — box plot или несколько гистограмм. Фактическая скорость конверсии по каналам.
3. **Кумулятивная конверсия по дням** — line chart: какой % лидов конвертируется к дню 1, 3, 7, 14, 30. Определяет оптимальное окно атрибуции.
4. **Скорость конверсии по соцдем** — средний days_to_purchase в разрезе пол/возраст/город.

---

### Tab 4: Registrations (детально)

1. **Доля квалифицированных лидов** (qual_lead) — тренд по дням. Качество входящего трафика.
2. **CR квал. vs неквал. лидов** — разница в конверсии.
3. **Разбивка по каналу активации** (guest_ref): `guest_act`, `ref_act`, `guest_ref_act`, `w/o ref/guest` — bar chart с CR. Эффект промо-механик на конверсию.
4. **Конверсия qual_lead x guest_ref** — квал. лид с гостевым промокодом vs квал. лид без.

---

### Tab 5: Guests (детально)

1. **CR по длительности гостевого** (added_days: 7 vs 14) — стоит ли давать 14 дней?
2. **CR по source_from** — UserReferral / DiscountPromoCode2 / Lead.
3. **Visits_count -> конверсия** — зависимость CR от количества визитов.
4. **Payouts_sum vs purchase_price** — unit-экономика: затраты на выплаты vs выручка с покупки. ROI по гостевым.
5. **Средний visits_count конвертировавшихся vs не конвертировавшихся** — Big Number пара.

---

### Tab 6: Comebacks

1. **Тренд офферов по дням** — объём comeback-офферов.
2. **Доля переданных в AmoCRM** (send_to_amocrm) — и CR отдельно для переданных и не переданных. Эффективность CRM-касания.
3. **Days_from_reg у камбэков** — распределение. Через сколько дней после регистрации люди получают comeback-оффер. Когорты: месяц, квартал, полгода.
4. **CR камбэков по days_from_reg когортам** — зависимость конверсии от длительности неактивности.

---

### Tab 7: Referrals

1. **Тренд реферальных лидов по дням**.
2. **Days_from_reg** — новые или старые пользователи активируют рефералки. Распределение.
3. **CR по days_from_reg когортам** — свежие пользователи конвертятся лучше через рефералку?
4. **Средний чек реферальных vs остальных типов**.

---

## Ключевые инсайты, которые дэшборд позволит получить

1. **Какой канал лидогенерации самый эффективный** — по CR и по выручке.
2. **Портрет идеального лида** — пол, возраст, город, устройство с максимальной конверсией.
3. **Эффект промо-механик** — гостевой доступ (7 vs 14 дней), реферальные промокоды — что работает лучше.
4. **Unit-экономика гостей** — payouts vs purchase_price.
5. **Оптимальное окно конверсии** — на какой день после лида реально происходит покупка.
6. **Качество трафика** — тренд qual_lead покажет деградацию или улучшение входящего потока.
7. **Эффективность CRM** — передача comeback в AmoCRM даёт ли uplift в конверсии.
8. **Географическая приоритизация** — какие города конвертят лучше, куда направить маркетинг-бюджет.

## Реализация в Superset

Рекомендуемый подход — два уровня datasets:

1. **Unified view** — объединить все 4 таблицы в один dataset с колонкой `lead_type`. Удобно для overview-чартов и сравнительного анализа.
2. **Отдельные datasets** — по одному на каждый тип лида. Необходимо для детальных табов (guests, regs), где есть уникальные поля (visits_count, qual_lead и т.д.).
