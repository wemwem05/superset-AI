**1. Add postgres-backup sidecar to docker-compose.yml (per D-01, D-02, D-03, D-04):**

Add a new service block after the `superset-beat` service and before the `volumes:` section:

```yaml
  # ---------------------------------------------------------------------------
  # PostgreSQL Backup — daily pg_dump to S3 with 7-day retention
  # ---------------------------------------------------------------------------
  postgres-backup:
    image: eeshugerman/postgres-backup-s3:16
    environment:
      SCHEDULE: '0 2 * * *'
      BACKUP_KEEP_DAYS: 7
      S3_REGION: ${S3_REGION}
      S3_BUCKET: ${S3_BUCKET}
      S3_PREFIX: superset-backups
      S3_ACCESS_KEY_ID: ${S3_ACCESS_KEY_ID}
      S3_SECRET_ACCESS_KEY: ${S3_SECRET_ACCESS_KEY}
      # S3_ENDPOINT: ${S3_ENDPOINT}
      POSTGRES_HOST: postgres
      POSTGRES_DATABASE: ${POSTGRES_DB}
      POSTGRES_USER: ${POSTGRES_USER}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
    depends_on:
      postgres:
        condition: service_healthy
    restart: unless-stopped
    deploy:
      resources:
        limits:
          cpus: '0.5'
          memory: 512M
        reservations:
          cpus: '0.1'
          memory: 128M
```

The tag `:16` matches the PostgreSQL server version (postgres:16-alpine). The `SCHEDULE` runs at 2 AM UTC daily. `BACKUP_KEEP_DAYS: 7` deletes backups older than 7 days. S3 credentials reference variables from `.env` (not hardcoded — per Pitfall 4 in research). The commented-out `S3_ENDPOINT` line is for non-AWS S3-compatible providers.

**NOTE on gzip compression (per D-04):** The `eeshugerman/postgres-backup-s3` image compresses all backups with gzip by default — backup files are produced as `.sql.gz`. No additional configuration is needed to satisfy D-04. This is a built-in behavior of the image, not an optional feature.

# General Superset cache (metadata, UI state): 5 min — low-cost to recompute
CACHE_CONFIG = {
    "CACHE_TYPE": "RedisCache",
    "CACHE_DEFAULT_TIMEOUT": 300,       # 5 min
    "CACHE_KEY_PREFIX": "superset_",
    "CACHE_REDIS_URL": f"{REDIS_URL}/0",

# Query result cache: 30 min — PostgreSQL source data refreshes at most hourly
DATA_CACHE_CONFIG = {
